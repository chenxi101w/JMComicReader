## 设计目标

将原有基于 pywebview + Flask 的漫画阅读器从移动端优先布局升级为**桌面窗口化彩色方案**：

- 窗口尺寸从 920px 居中布局拓宽为 **1280×920**，更适合 Windows 桌面鼠标操作。
- 采用左侧固定 **240px 侧边栏导航**，替代移动端的底部 Tab 栏。
- 引入 **8 组糖果渐变封面色** + **8 组分类强调色**，形成鲜明的彩色视觉风格。
- 卡片、标签、按钮使用更大的圆角（16px / 15px），贴合 Material 3 的圆润语言。
- 保留原有 Aurora 系统的青蓝→紫主色调，但放大并多彩化。

## 各界面要点

### 01 主页
- 左侧导航：主页高亮（渐变背景）、搜索 / 书架 / 设置默认态。
- 顶部：「为你推荐」标题 + 主题切换 + 更多按钮。
- 搜索行：复用搜索框组件，placeholder 为「搜索漫画 / 作者 / 标签…」。
- 推荐区：两行各 4 张彩色渐变卡片，标题 + 分类·话数元信息。
- 热门分类：8 个彩色 pill 标签横向排列。

### 02 搜索页
- 顶部标题「搜索发现」。
- 大搜索框 + 渐变「搜索」按钮。
- 筛选条件：全部（激活态深色）、漫画 / 作者 / 标签 / 高级（浅紫底）。
- 最近搜索：浅灰底 pill，可点击快速填充。
- 搜索结果：4 张彩色卡片横向展示。

### 03 书架页
- 顶部标题「我的书架」。
- 标签切换：全部 / 已下载 / 收藏 / 历史。
- 统计卡：128 已下载 / 36 收藏 / 512 阅读历史，数字使用对应强调色。
- 继续阅读：4 张彩色卡片。

### 04 阅读器
- 全屏漫画页占位，带阴影的圆角卡片，真实内容替换为漫画图片。
- 顶部：返回书架、章节标题、目录 / 设置按钮。
- 底部：页码「12 / 24」、上一页 / 下一页，下一页使用主渐变强调色。

### 05 设置页
- 顶部标题「设置」。
- 分组块式布局（JM Reader 风格）：外观 / 下载 / 阅读 / 关于。
- 每行左侧标签、右侧当前值或控制色块。
- 强调色使用主渐变圆点示意。

## 桌面化调整说明

- **宽度**：从移动端 920px 拓宽到 1280px，单屏可展示 4 列卡片，阅读器区域更宽敞。
- **导航**：底部 Tab 改为左侧固定侧边栏，鼠标操作效率更高，且保留 Logo + 用户信息。
- **圆角**：卡片圆角从 10-12px 提升到 16px，标签使用 15px pill，更圆润现代。
- **彩色**：每本漫画使用不同渐变封面，分类标签使用独立强调色，避免单一主色单调。
- **层次**：设置页采用分组卡片，统计使用独立色块，信息分区更清晰。

## 还原建议

1. 在 CSS 中引入 `tokens.css` 的变量。
2. 漫画卡片封面根据分类动态应用 8 组渐变之一。
3. 分类标签统一使用 chip 组件，背景 / 文字成对取值。
4. 侧边栏激活态使用主渐变填充 + 白色文字，未激活态为透明底 + 深色文字。
5. 阅读器背景使用 `#F7F8FC` 浅灰，漫画页卡片使用白色底 + 阴影，减少视觉疲劳。
