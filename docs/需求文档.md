# jmcomicreader（Windows）需求文档

> PC 端桌面漫画阅读与管理工具：搜索、在线阅读、批量下载、书架管理、智能推荐。基于 **Python + Flask + jmcomic + pywebview**。
> 详细接口见 `API.md`；架构见 `架构报告.md`；函数索引见 `功能函数清单.md`；排障见 `TROUBLESHOOTING.md`；发版铁律见 `已知坑与发版铁律.md`。
> **复刻方向**：与 Android 版（v6.0.13）对齐功能，按「数据层 → 接口 → 前端 → 美化」逐模块复刻。

## 核心定位

- **搜索与下载中枢**：调用 jmcomic 客户端检索漫画、批量下载、管理本地库。
- **桌面优先**：pywebview + Edge WebView2 承载本地 Flask 服务，数据与程序分离（`UserData/`）。
- **本地库管理**：SQLite 维护漫画元数据、分类、下载状态、搜索/下载/阅读历史、拉黑、同义词。

## 验收标准

- 下载并发受 `max_concurrent_downloads` 控制，稳定性达标。
- 本地翻页即时，搜索首屏 3s 内返回。
- 数据迁移 / 备份：拷贝 `UserData/` 即可在另一机恢复。

## 技术栈

- Python 3.13 + Flask（`core/app.py`）
- SQLite（`core/models/database.py`，9 张 DDL）
- jmcomic 爬虫客户端（`core/services/jm_crawler.py`）
- pywebview + Flask 桌面壳（`desktop_app.py`）
- PyInstaller onedir 打包（`build/JMComicReader.spec` + `build/_build.py`）
