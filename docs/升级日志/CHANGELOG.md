## v2.13.1 — 2026-09-25

### 更新内容
- **搜索范围分段控件（Tab）终于生效**：原来「全部 / 标题 / 作者 / 标签」四个分段按钮只是切换高亮（`is-active`），从不真正参与搜索。现在它们真实决定后端请求路由与结果语义，`doSearch` 按范围分流：`comic`→`/api/search/keyword`、`title`→关键词限标题、`author`→`/api/search/author`、`tag`→`/api/search/tags`；纯数字 ID 直接走 `/api/search/jm/<id>` 精确查漫画。所选范围写入条件条（`范围:标题/作者/标签`）。
- **范围偏好持久化**：选中的分段范围随排序 / 时间 / 方向一起存进 `SearchPrefs`（localStorage `jm_search_prefs`），下次进搜索页自动恢复，不再每次重置成「全部」。
- **结果关键词高亮**：命中卡片的标题与作者名里匹配关键词的片段套 `<mark>` 高亮（主题色浅底 + 加粗），一眼定位；标签范围（`scope==='tag'`）下不强行高亮整段标签词。
- **空态个性化推荐**：搜不到结果时，空态区按「我的收藏标签 + 快捷标签」去重取最多 12 个渲染成可点芯片（`#searchEmptySuggest`），点一下就把该标签塞进筛选并立即重搜，给无结果页一个出口。
- **展开面板（统一下拉）打磨**：面板列布局在窄屏（≤700px）自动改竖排、去掉列分隔线；分段控件 `.d-mode.is-active` 统一成浅紫底 + 主题色字 + 内描边，与侧栏选中态视觉语言一致。
- 缓存键 `?v=64` → `?v=65`。

### 功能简介
- 搜索范围分段（全部 / 标题 / 作者 / 标签）真实生效并持久化；结果高亮；空态给标签推荐芯片；展开面板窄屏自适应。

### 使用说明
- 解压 `JMComicReader_v2.13.1_portable.zip` → 双击 `JMComicReader.exe`
- 需要 Windows 10/11（自带 WebView2 运行时）
- 首次启动在 exe 同级目录自动生成 `UserData/`（配置与下载存放处）

### 已知问题
- 暂无

## v2.13.0 — 2026-09-25

### 更新内容
- **书架分类 UI 合一：双层变单层。** 原来「块状级联下钻导航（`#catNav`）+ 折叠起来的分类管理树（`#catTreeWrap`）」两套界面并存，认知负担重、操作入口分散（选分类在一处、改层级在另一处）。现在**只保留一棵分类树**，直接常驻在书架左侧栏（`.lib-side`，232px 宽、sticky 吸顶、窄窗口 <900px 自动改为上方横条）：选分类、拖层级、重命名、删除，全部在这一棵树里完成。
- **分类树结构**：顶部三行虚拟视图（全部漫画 / 我的收藏 / 未归类），一条分隔线（`.tree-sep`），下面是真实的分类树。虚拟行与真实分类行共用一套 `.tree-item` 样式与交互。
- **新增「未归类」收件箱**：列出所有没归入任何分类的漫画（后端 `/api/downloaded?uncategorized=1` 筛选），树上的数字实时统计。**把漫画拖到「未归类」行 = 取消它现有的全部分类**，不用再进弹窗逐个取消勾选。
- **分类重命名 / 删除**取代原来的「移动到其他分类」按钮：鼠标悬停在分类行上出现 ✎ / 🗑 两个小按钮（`title` 提示）。
  - 重命名走 `PUT /api/categories/<id>`。
  - 删除对齐手机版的 `deleteCategoryWithReassign`：先查 count（`GET /api/categories/<id>?count_only=1`），**空的直接删**，非空的弹出模态框列出可选去向（自动排除自身及其子孙）+「未归类」，必须选一个才允许删（`DELETE` 带 `reassign_to`），不会丢书。
- **拖拽增加非法目标预判**：把一个分类拖到它自己或它的子孙分类下时，目标行即时变红虚线（`.drop-invalid`）且不接受放下，松手还会提示「不能移动到其子分类下」（后端本来也会拒，这里提前给视觉反馈）。
- **收藏数角标**改挂在树的「我的收藏」行上，类名由 `.cat-block__badge` 换成语义更准的 `.tree-item__badge`（选中行时转为渐变胶囊）。
- 漫画拖到分类上 = **单选归属**（`PUT /api/comic/<id>/categories` 只发一个 id），拖到「未归类」= 清空归属。
- **清理**：删除 `renderCatNav` / `_applyCatSelection` / `_catPath` / `openCategoryMovePicker` / `collectDescendantIds` 等已废弃代码，删除 `.cat-nav` / `.cat-crumb` / `.cat-block*` / `.cat-move-btn` 共 30 余条孤儿 CSS；`library.html` 里那段控制折叠的 `<script>` 一并去掉。
- 缓存键 `?v=63` → `?v=64`。

### 书架侧栏视觉打磨（精致侧栏树）
- **选中态改为圆角药丸 + 浅紫底**（`--d-grad-soft` 渐变 + 内描边），不再是生硬的整行高亮；选中行的数量角标同步染上主题色。
- **分组小标题**：分类树内新增「视图」「我的分类」两行迷你小标题（`.tree-group`），把虚拟视图与真实分类在视觉上归组。
- 增删按钮（✎ / 🗑）维持「悬停才出现」，不污染静态视图；hover 底色对齐到 `--d-bg-2`，拖放高亮对齐到 `--d-grad-soft`。

### 功能简介
- 底部三 Tab：书架 · 发现 · 设置（启动页为书架）
- 书架：左侧单一分类树（全部 / 收藏 / 未归类 + 分类层级），拖拽改层级与归属，重命名 / 删除分类
- 发现：订阅新作 + 为你推荐；搜索框支持全部 / 标题 / 作者 / 标签四种范围
- 阅读器：章节切换、缩放、预加载、滚轮行为设置
- 下载管理、回收站（7 天宽限期）、漫画详情页
- 标签库：兴趣库 / 实验库、三态画像（喜欢 / 讨厌 / 无关）、智能关联、同义词、汇总统计

### 使用说明
- 解压 `JMComicReader_v2.13.0_portable.zip` → 双击 `JMComicReader.exe`
- 需要 Windows 10/11（自带 WebView2 运行时）
- 首次启动在 exe 同级目录自动生成 `UserData/`（配置与下载存放处）

### 已知问题
