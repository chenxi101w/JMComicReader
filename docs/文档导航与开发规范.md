## 二、开发标准（必须遵守）

### 1. 版本号规范（`docs/升级日志/版本规范.md`）
- 三段式 `X.Y.Z`：
  - **major（X）** +1 = 大改 UI / 全面优化
  - **minor（Y）** +1 = 新增 / 删除 / 升级功能
  - **patch（Z）** +1 = 修 bug
- 每次发版**同时**更新 `VERSION`（根目录，运行时读取 + 便携包命名）与 `docs/升级日志/CHANGELOG.md`。

### 2. 需求文档维护约定（`docs/需求文档.md`）
- 每一次代码改动，都要在该文档末尾「变更记录」追加一条，并同步更新版本号与 `CHANGELOG.md`。

### 3. 发版铁律（数据安全，见 `docs/已知坑与发版铁律.md`）
- 任何 SQLite 表结构变更（加列 / 建表 / 建索引）：建表一律 `CREATE TABLE IF NOT EXISTS`；**加列一律 `ALTER TABLE ... ADD COLUMN` 并 try/except 幂等**，绝不清表重建丢用户数据。
- 配置默认值新增走 `DEFAULT_CONFIGS`，已存在的键用 `INSERT OR IGNORE` 保留用户现值。

### 4. 技术栈约束
- Python 3.13 · Flask · jmcomic · Jinja2 模板 + 原生 JS/CSS · pywebview（Edge WebView2）。
- 打包：PyInstaller onedir（`build/JMComicReader.spec` + `build/_build.py`）。
- 数据目录：源码运行时在项目根；打包后在 exe 同级 `UserData/`（见 `desktop_app.py`）。
