# JMComicReader（Windows）· 功能函数清单

> 全局功能函数索引，按模块整理。以磁盘真实代码为准，不编造。
> 技术栈：Python 3.13 · Flask · jmcomic · Jinja2 + 原生 JS/CSS · pywebview。
> 复刻基线：Android v6.0.13（本清单为 Windows 当前 v2.4.12 现状，复刻时同步扩充）。

***

## 一、`core/models/database.py`（数据层：SQLite，8 张表）

> 表：`downloaded_comics` / `categories` / `comic_categories` / `search_history` / `download_history` / `reading_history` / `system_config` / `blocklist` / `aliases`（共 9 条 DDL，见 `ALL_DDL`）。

### 1.1 初始化 / 配置

| 函数                                                        | 说明                                                                                   |
| --------------------------------------------------------- | ------------------------------------------------------------------------------------ |
| `init_database()`                                         | 建表（IF NOT EXISTS）+ 写默认配置（INSERT OR IGNORE）+ image\_quality 纠偏 + `chapter_count` 增量迁移 |
| `get_system_config(key)` / `set_system_config(key,value)` | 系统配置 KV 读写                                                                           |
| `get_image_quality_params()`                              | image\_quality → (quality, subsampling)，供 JPEG 保存                                    |
| `DEFAULT_CONFIGS`                                         | 默认配置元组（并发数 / 缓存 / 主题 / 代理 / 搜索上限等）                                                   |

### 1.2 分类

| 函数                                                                                | 说明                    |
| --------------------------------------------------------------------------------- | --------------------- |
| `get_all_categories()` / `get_category_tree()`                                    | 平铺列表 / 递归树（节点带子孙漫画数）  |
| `create_category` / `update_category` / `delete_category` / `set_category_parent` | 分类 CRUD + 移动（删除时子级提升） |
| `get_category_descendant_ids(cat_id)`                                             | 后代 id 列表，供移动环检测       |
| `get_comic_categories` / `get_all_comic_categories` / `set_comic_categories`      | 漫画↔分类多对多              |

### 1.3 历史记录

| 函数                                                                                                     | 说明                           |
| ------------------------------------------------------------------------------------------------------ | ---------------------------- |
| `add_search_history` / `get_search_history_aggregated(limit)`                                          | 搜索历史写入 / 按(type,content)聚合频次 |
| `add_download_history` / `get_download_history` / `delete_download_history` / `clear_download_history` | 下载历史                         |
| `add_reading_history` / `cleanup_old_records(days)`                                                    | 阅读历史 + 30 天自动清理              |

### 1.4 拉黑 / 别名

| 函数                                                                                                                  | 说明                  |
| ------------------------------------------------------------------------------------------------------------------- | ------------------- |
| `normalize_author(author)`                                                                                          | 作者名归一化（去空白转小写）      |
| `add_block` / `remove_block` / `remove_block_by_value` / `get_blocks` / `get_blocked_sets` / `get_local_block_hits` | 拉黑（author/work/tag） |
| `add_alias` / `remove_alias` / `get_aliases` / `get_alias_map`                                                      | 别名 / 同义词映射          |

### 1.5 漫画关系状态（comic\_status 位掩码，v2.5 复刻 Android）

> `comic_status`：主键 = jm 号，不随 downloaded\_comics 级联删除。`status` 位掩码见 `database.py` 常量：`BIT_LOCAL(1)/FINISHED(2)/DOWNLOADED(4)/FAVORITE(8)/BLOCKED(16)/TAGS_RECORDED(32)/TAGS_CHECKED(64)`。`ext` 为 JSON 兜底字段。

| 函数                                                                                                                          | 说明                         |
| --------------------------------------------------------------------------------------------------------------------------- | -------------------------- |
| `get_comic_status` / `get_all_comic_statuses`                                                                               | 读单本 / 全部关系状态               |
| `ensure_comic_status(book_id)`                                                                                              | 状态行缺失则补充（INSERT OR IGNORE） |
| `upsert_comic_status(book_id, *, status, title, author, cover_url, tags, view_count, last_read_at, ext, preserve_ext=True)` | 整行写快照 + 位掩码；默认保留已有 ext     |
| `set_status_bits(book_id, bits)` / `clear_status_bits(book_id, bits)`                                                       | 置位（OR）/ 清位（AND NOT）        |
| `bump_status_view_count(book_id)`                                                                                           | 查看次数 +1                    |
| `touch_status_read(book_id, ms)`                                                                                            | 刷新最近阅读时间                   |
| `delete_comic_status` / `clear_all_comic_status`                                                                            | 删单本 / 清空关系状态（隐私）           |
| `has_bit(status, bit)`                                                                                                      | 位掩码判定位                     |

### 1.6 标签库（tag\_library / tag\_library\_exp，v2.5 复刻 Android）

> 两张结构一致、互相独立的表：`tag_library` 兴趣库（搜索命中累积，供算法/设置页浏览）、`tag_library_exp` 实验库（批量抓取 JM 号的全量标签字典）。主键 `tag`（小写归一化），`count` 累计次数，`last_seen_at` 最近命中时间(ms)。

| 函数                                        | 说明                                                                |
| ----------------------------------------- | ----------------------------------------------------------------- |
| `bump_tag(tag, ts_ms=None, *, exp=False)` | 标签命中 +1：首插 count=1，已有则 count+1 并刷新 last\_seen\_at；`exp=True` 走实验库 |
| `get_tag_library(*, exp=False)`           | 快照，按 count 降序、次级按 last\_seen\_at 降序                               |
| `get_tag_library_count(*, exp=False)`     | 标签总数（管理页展示）                                                       |
| `clear_tag_library(*, exp=False)`         | 清空标签库，返回删除条数（设置页 / 实验库重建）                                         |

### 1.7 订阅（subscriptions / sub\_updates，v2.5 复刻 Android）

> `subscriptions` 作者订阅（收藏作者、检查更新、新作计数）；`sub_updates` 订阅新作记录（检查时逐部落库，书架「订阅更新」区块展示）。时间戳均用毫秒。

| 函数                                                                    | 说明                                            |
| --------------------------------------------------------------------- | --------------------------------------------- |
| `get_subscriptions`                                                   | 全部订阅，按订阅时间倒序                                  |
| `find_subscription_by_author(author)`                                 | 按作者名精确查找；无则 None                              |
| `upsert_subscription(author, created_at=None)`                        | 订阅作者（REPLACE 幂等），返回 id                        |
| `delete_subscription(sub_id)` / `clear_all_subscriptions`             | 删单条 / 清空全部订阅                                  |
| `note_subscription_checked(author, ts_ms)`                            | 仅刷新最近检查时间                                     |
| `note_subscription_update(author, ts_ms, delta, title)`               | 检查发现新作：刷新检查/更新时间、累加 new\_count、记录 last\_title |
| `clear_subscription_new_count(sub_id)`                                | 新作计数清零（用户已查看）                                 |
| `get_sub_updates(*, unseen_only=False)` / `get_sub_updates_by_author` | 新作记录（可只看未查看）                                  |
| `insert_sub_update(author, book_id, title, cover_url, found_at=None)` | 记录一条新作（默认忽略重复）                                |
| `mark_sub_update_seen(book_id)` / `mark_all_sub_updates_seen`         | 标记已查看（单本 / 全部）                                |
| `delete_sub_updates_by_author` / `clear_all_sub_updates`              | 删某作者 / 清空新作记录                                 |

## 二、`core/app.py`（Flask 路由层）

> 页面路由：`/` `/home` `/search` `/library` `/reader/<id>` `/settings` `/downloads`。

| API                                                                                                               | 说明                                                |
| ----------------------------------------------------------------------------------------------------------------- | ------------------------------------------------- |
| `/api/search/jm/<id>` `keyword` `tags` `author` `combined` `enrich`                                               | 搜索（JM号/关键词/标签/作者/联合/标签补全）                         |
| `/api/recommend`                                                                                                  | 自动推荐（兴趣种子 + 离线降级 + 120s 缓存）                       |
| `/api/cover/<id>` `/api/cover/downloaded/<id>`                                                                    | 封面                                                |
| `/api/download/<id>` `/api/download/batch`                                                                        | 下载（单本 / 批量，统一走并发线程池）                              |
| `/api/download/progress...`                                                                                       | 下载进度（GET 轮询 / DELETE 移除 / GET 全部）                 |
| `/api/download/history`                                                                                           | 下载历史读写清空                                          |
| `/api/categories`                                                                                                 | 分类树 / CRUD / 移动                                   |
| `/api/comic/<id>/categories` (GET/PUT)                                                                            | 漫画分类读写                                            |
| `/api/downloaded`                                                                                                 | 已下载列表（标注拉黑灰显）                                     |
| `/api/read/<id>` `/api/read/<id>/chapter/<cid>` `/api/comic/<id>/page/<page>`                                     | 阅读 / 章节 / 页面                                      |
| `/api/delete/<id>`                                                                                                | 删除已下载漫画                                           |
| `/api/cache/status` `/api/cache/clear`                                                                            | 缓存状态 / 清理（保护已下载封面）                                |
| `/api/settings` (GET/POST)                                                                                        | 设置读写白名单                                           |
| `/api/blocklist` `/api/aliases`                                                                                   | 拉黑 / 别名管理、预览、影响查询、同义词建议                           |
| `/api/status/<jm_id>` `/api/status/favorites` `/api/status/<jm_id>/favorite` `/finished` `/view` `/read` (DELETE) | 漫画关系状态读 / 收藏列表 / 收藏翻转 / 读完翻转 / 次数+1 / 最近阅读 / 清空画像 |
| `/api/subscriptions` `/api/sub_updates` `/api/tag-library`                                                        | 订阅 CRUD+新作标记 / 兴趣库+实验库查询清空命中（对齐 Android）          |

辅助：`_filter_blocked`（统一黑名单过滤）、`_get_dl_executor`（并发下载线程池）、`_run_download_task`、`_offline_recommend`、`_schedule_history_cleanup`（每日清理守护线程）。

## 三、`core/services/`（业务服务层）

> 各文件核心入口（被 `app.py` 调用，事实来源）：

| 模块                                       | 职责                                   | 关键入口                                                                                                                                        |
| ---------------------------------------- | ------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------- |
| `jm_crawler.py`（`JMCrawler`）             | JM 客户端：域名切换、scramble 解码、搜索 / 详情 / 封面 | `search_by_keyword` `search_by_tags` `search_by_author` `get_comic_info` `get_cover_url` `get_search_result_details` `_parse_count`         |
| `download_manager.py`（`DownloadManager`） | 文件 I/O：按规则保存图片、目录结构、临时下载恢复           | `download_comic(jm_id, comic_info, cb)` `recover_temp_downloads()`                                                                          |
| `comic_manager.py`（`ComicManager`）       | 本地漫画枚举、章节、页面路径；单条元数据查询               | `get_comic_meta` `get_downloaded_comics` `is_comic_downloaded` `get_comic_chapters` `get_comic_page_path` `is_local_chapter` `delete_comic` |
| `filter_service.py`                      | 业务规则：拉黑过滤 + 标签/作者别名展开 + 同义词建议        | `postprocess_results` `expand_tags` `expand_author` `suggest_aliases`（含 `SEED_SYNONYMS`）                                                    |

## 五、`web/`（前端）

* `templates/`：`base/search/library/reader/settings/downloads/home`（Jinja2）

* `static/js/app.js`：单文件前端逻辑（搜索 / 推荐 / 书架 / 阅读 / 设置 / 下载管理）

* `static/css/style.css`：单文件样式

> 复刻 Android 新功能时，前端需按页面拆分或同步扩充 `app.js`/模板；改动后静态资源 `?v=` 版本号 +1 强制刷新。

## 六、覆盖说明

* **搜索**：`app.py` search 系列接口 + `filter_service.expand_*` + `jm_crawler.search_*` + `_filter_blocked`。

* **下载**：`app.py` download 接口 + `_get_dl_executor` + `download_manager.download_comic`。

* **阅读**：`app.py` read/page 接口 + `comic_manager` 本地目录扫描。

* **书架**：`app.py` downloaded 接口 + `comic_manager` + `database` 分类/历史。
