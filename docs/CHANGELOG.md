# 更新日志 (Changelog)

每个便携版发布时，在 `dist_out/` 同步生成 `JMComicReader_vX.Y.Z_更新说明.md`（随包给下载者），
并按下述格式在此文件追加一节。

---

## 模板（每发一个新版本，复制本节填写）

```
## vX.Y.Z — YYYY-MM-DD
### 更新内容
- （相对上一版的功能新增 / 问题修复 / 内部调整）

### 功能简介
- （本版包含的主要能力，给新用户看）

### 使用说明
- 解压 `JMComicReader_vX.Y.Z_portable.zip` → 双击 `JMComicReader.exe`
- 需要 Windows 10/11（自带 WebView2 运行时）

- （如有；无则写「暂无」）
```

## v2.4.4 — 2026-08-09

### 更新内容
- 版本号 2.4.3 → 2.4.4（重新发布，区分此前已上传的 2.4.3）
- 内部结构调整：清理冗余文档、按类型重组源码目录（`build/` 收纳打包配置、`docs/` 统一文档），**对最终用户使用无影响**
- 打包流程增强：构建后自动产出 `JMComicReader_vX.Y.Z_portable.zip`（解压即用）
- 内置此前一轮代码审查的全部质量修复：
  - 路径遍历防护（非法 `chapter` 参数被拒，返回 400）
  - 跨域请求收紧（仅允许本机来源，拒绝外部 `Origin`）
  - 设置项白名单（忽略非法配置键，不写入 settings）
  - 历史记录清理改为守护线程（不再阻塞进程退出）
  - 阅读接口返回标准 JSON

### 功能简介
- 漫画搜索 / 详情 / 章节浏览
- 本地下载与管理
- 阅读历史记录
- 分类树浏览

### 使用说明
- 解压 `JMComicReader_v2.4.4_portable.zip` → 双击 `JMComicReader.exe`
- 需要 Windows 10/11（自带 WebView2 运行时）
- 首次启动在 exe 同级目录自动生成 `UserData/`

### 已知问题
- 暂无（GUI 与真实下载链路建议本机首次解压后实机验证一次）
