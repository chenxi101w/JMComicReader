# JMComicReader（Windows）· 版本号规范

> ★ 发版必读。三段式版本号，进位规则如下。

## 一、X.Y.Z 进位规则

- **major（X）** +1 = 大改 UI / 全面优化 / 架构调整
- **minor（Y）** +1 = 新增 / 删除 / 升级一项功能
- **patch（Z）** +1 = 修复 bug / 小规模内部调整

## 二、每次发版必须同步更新的文件

| 文件 | 更新内容 |
|------|----------|
| `VERSION`（根目录） | 写入新版本号，例如 `2.5.0`（运行时读取 + 便携包命名） |
| `docs/升级日志/CHANGELOG.md` | 按模板追加一节新版本记录 |
| `docs/需求文档.md` | 末尾「变更记录」追加一条 |
| `README.md`（可选） | 更新「功能一览」「更新日志」高亮条目 |

## 三、便携包命名

构建完会生成 `dist_out/JMComicReader_vX.Y.Z_portable.zip`，命名与 `VERSION` 保持一致。
