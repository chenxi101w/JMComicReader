# JMComicReader（Windows）· 真机验证清单

> 发版前逐项勾选。冒烟回归以**真实本地目录**验证为准，避免仅靠静态检查。

## 一、启动 / 基础

- [ ] 双击 `JMComicReader.exe`（或 `python desktop_app.py`）能正常开窗，无报错
- [ ] 首次启动生成 `UserData/`（打包版）或项目根数据目录（源码版）
- [ ] 无 WebView2 时优雅回退到系统浏览器
- [ ] 固定端口（`.app_url`）生效，localStorage 持久化

## 二、搜索

- [ ] 关键词 / 标签 / 作者 / JM号 四维度搜索正常
- [ ] 搜索结果标签按需补全（`/api/search/enrich`）不丢
- [ ] 黑名单在搜索入口生效（屏蔽作品 / 作者 / 标签不再出现）
- [ ] 作者 / 标签同义词展开生效
- [ ] 搜索偏好库：历史 / 收藏 / 编辑 / 回收站恢复 / 一键回填

## 三、推荐（主页）

- [ ] 基于搜索偏好的「为你推荐」能出结果（含网络不可用的离线降级）
- [ ] 点推荐里的标签/作者直达搜索

## 四、下载与书架

- [ ] 单本下载、批量下载真正限并发（`max_concurrent_downloads` 生效）
- [ ] 下载完成立即可见、书架统一管理
- [ ] 下载历史 / 进度 / 失败记录入库，卡住任务可清理
- [ ] 分类树（无限层级）创建 / 重命名 / 移动 / 删除，环检测生效
- [ ] 漫画长按指派分类，删除分类子级提升不误删

## 五、阅读

- [ ] 章节列表 / 章节切换 / 阅读进度自动记录
- [ ] 本地翻页即时、章节内预取不转圈
- [ ] 滚轮缩放（以光标为中心）+ 方向键平移正常；「滚轮行为」设置生效

## 六、设置 / 数据

- [ ] 主题亮 / 暗 / 跟随系统切换即时生效
- [ ] 代理、并发数、搜索上限、画质等设置保存并重启后保持
- [ ] 缓存清理：只清自动缓存，不动手动下载与已下载漫画封面
- [ ] 数据迁移 / 备份：整个 `UserData/` 拷贝即迁移

## 七、回归重点（改过哪块重点验哪块）

- [ ] 搜索历史每日清理守护线程不阻塞退出
- [ ] 历史 / 下载记录清理正常
