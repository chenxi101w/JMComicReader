# JMComicReader / JM漫画阅读器（Windows）

基于 [pywebview](https://pywebview.flowrl.com/) + Flask 的 Windows 桌面漫画阅读 / 下载器，界面为移动优先的响应式 Web UI，支持搜索、阅读、下载、书架管理与推荐。
