## v2.4.8 — 2026-08-10

### 更新内容
- 版本号 2.4.7 → 2.4.8
- 修复推荐页标签消失：v2.4.7 的标签按需补全只接到了搜索页，推荐页（由关键词 / 作者种子并发合并而成，结果本身不带 tags）仍缺标签。已将 `enrichSearchCards` 改为**按 grid 作用域**（搜索页 / 推荐页各自独立查询、独立防抖），并在推荐渲染后同样调用 `/api/search/enrich` 回填。
- 静态资源版本 `?v=34` → `?v=35` 强制刷新。

### 功能简介
- 搜索页、推荐页现在都会在渲染后约 1 秒内补齐标签；本就带标签的卡片被 `!c.tags` 过滤跳过，不重复请求。

### 使用说明
- 解压 `JMComicReader_v2.4.8_portable.zip` → 双击 `JMComicReader.exe`
- 需要 Windows 10/11（自带 WebView2 运行时）
- 首次启动在 exe 同级目录自动生成 `UserData/`

### 已知问题
- 暂无

## v2.4.7 — 2026-08-10

### 更新内容
- 版本号 2.4.6 → 2.4.7
- 修复搜索结果标签消失：v2.4.5 为提速去掉了"逐个并发抓详情补标签"，而前端按需调 `/api/search/enrich` 补标签的逻辑此前从未接线，导致关键词搜索结果卡片不再显示标签。已在 `web/static/js/app.js` 接上补全——渲染后收集缺标签卡片，批量（每批 12 个、350ms 防抖）调 `enrich`，回填 DOM 并重新绑定事件；已补作品写入详情缓存，翻页 / 重复搜索标签不丢。
- 静态资源版本 `?v=33` → `?v=34` 强制刷新。

### 功能简介
- 关键词搜索即时返回（无标签），约 1 秒内标签补齐；已补过的作品重复搜索秒出。

### 使用说明
- 解压 `JMComicReader_v2.4.7_portable.zip` → 双击 `JMComicReader.exe`
- 需要 Windows 10/11（自带 WebView2 运行时）
- 首次启动在 exe 同级目录自动生成 `UserData/`

### 已知问题
- 暂无

## v2.4.6 — 2026-08-10

### 更新内容
- 版本号 2.4.5 → 2.4.6
- 搜索进一步优化：
  - 客户端跨请求复用（HTTP keep-alive，保留连接池），且原本每次搜索都触发的 JM 域名更新请求降为仅首次。
  - 搜索结果内存缓存（120s TTL）：相同查询、翻回上一页即时返回，跳过 JM 网络请求；限流 / 抽风时更稳。
  - 搜索结果直接带本地构造的封面 URL，省掉每卡片 `/api/cover` 后端往返，浏览器直连 JM CDN 拉图，列表一渲染封面即开始加载。
- 静态资源版本 `?v=32` → `?v=33` 强制刷新。

### 功能简介
- 搜索更顺滑、更省网络，翻页 / 重复搜索秒回。

### 使用说明
- 解压 `JMComicReader_v2.4.6_portable.zip` → 双击 `JMComicReader.exe`
- 需要 Windows 10/11（自带 WebView2 运行时）

## v2.4.5 — 2026-08-10

- 版本号 2.4.4 → 2.4.5
- 修复搜索变慢：原关键词搜索后逐个并发抓详情补标签 / 作者（一次多打十几 ~ 二十请求，3s → 5s+），改为只返回列表、标签 / 作者在详情页或按需补全，搜索回到 3s 内。
